Features

What is in the box

Everything is installed and configured on first login. Nothing to assemble.

Local AI

Models run on your own hardware. Nothing leaves your PC unless you choose a hosted agent.

  • Hardware detection. llmfit checks CPU, GPU and memory and lists the models that fit.
  • Ollama. Runs on 127.0.0.1 only and starts with the system.
  • Embeddings. A local embedding model is included for search over your own files.
  • Model manager. Add or remove models from a window, or with zom models.
  • Ask AI to Explain. Right-click any file and a local model explains it.

Coding agents

Six agents sit in the start menu. Each opens in a terminal and installs itself the first time you use it.

Codex
Claude Code
OpenCode
Grok
Gemini CLI
Qwen Code
  • Agents menu. Codex, Claude Code, OpenCode, Grok, Gemini CLI and Qwen Code.
  • Herdr. Persistent terminal workspaces, so agent sessions survive closing the window.
  • Continue in VS Code. Pre-configured to talk to your local model.
  • Your accounts. Hosted agents need their own account and a network connection.

Desktop

A dark, flat desktop that stays out of the way. Mouse-first, with no tiling to learn.

  • Matte black theme. Charcoal surfaces with amber for focus and active states.
  • AI-first start menu. Agents and Local LLM come first; every other app is in All Apps and search.
  • Wallpapers. Five polygonal 4K scenes. Switch with zom bg next.
  • One palette. The shell, GTK, VS Code, Herdr, btop and the terminal share the same colors.

Developer tools

The toolchain is installed system-wide, so every user account gets it.

  • Runtimes. Node LTS, Python 3.12 and Go, managed by mise.
  • Editor. Microsoft VS Code with GitLens, Prettier, Python and Go extensions.
  • Terminal. Starship, lazygit, lazydocker, btop, bat, eza, fd, fzf, ripgrep, zoxide, neovim and tmux.
  • Containers and Git. Docker with Compose, and the GitHub CLI.

Everyday apps

A workstation is more than a terminal.

  • Browse and write. Chromium, Obsidian and LibreOffice.
  • Create. OBS Studio, Kdenlive, Pinta and MPV.
  • Utilities. Mission Center, CopyQ clipboard history, LocalSend and Flameshot.

Maintenance

One tool keeps the whole stack healthy.

  • zom update Updates apt, Flatpak apps, runtimes and models.
  • zom doctor Checks Ollama, runtimes, editors, GPU and disk.
  • Safe to re-run. The installer changes nothing it does not need to, so you can run it again after any update.
  • New users. Every new account inherits the same setup.
