Features

What is in the box

Noctra sets everything up for you the first time you log in. There is nothing to assemble.

One shortcut finds everything

Press the Windows key and Space from anywhere. It is the only shortcut you need to learn.

  • What it finds. Apps, files and folders, clipboard history and the web.
  • Your browser history, if you want it. After you have used a browser, Noctra asks whether to include its history. It stays on your computer, and you can turn it off in the search settings.
  • A short welcome. The first time you log in, a welcome shows you the shortcut, where familiar things are, and your AI options.

AI on your own computer

The AI models run on your PC, not on someone else's server.

  • Graphics card drivers. If your PC has an NVIDIA or AMD graphics card, Noctra installs its driver during setup, with CUDA for NVIDIA and ROCm for supported AMD cards, so local models run on the card instead of the processor. Restart once after the first install.
  • Picks models that fit. Coming soon Noctra will check your processor, graphics card and memory, then show which models run well.
  • Private prompts. With a local model, your prompts and files stay on your computer. Online assistants send what you give them to their own servers.
  • Simple model list. Pick a model from a list and download it from a window.
  • Right-click to explain. Right-click any file and ask the AI what it says.

AI coding assistants

Hermes comes ready to use, and six command-line assistants sit in the start menu next to it. Each of the six opens in a terminal and sets itself up the first time you use it.

  • One menu. Hermes, Codex, Claude Code, OpenCode, Grok, Gemini CLI and Qwen Code.
  • Hermes. A desktop agent that is free to start with no sign-up. Its free tier runs on Nous Research’s servers, so what you type to it leaves your computer. One click switches it to your local model instead.
  • In your editor. The code editor comes ready to chat with your local model.
  • Optional session manager. Herdr, included with Noctra, keeps terminal sessions running after you close the window.
  • Your own accounts. Online assistants need their own account and an internet connection.

A calm dark desktop

Easy on the eyes, and it works the way you expect.

  • Dark theme. Charcoal with amber highlights.
  • Familiar layout. A Start button above a centred dock, window buttons, a task manager, and a top bar with the clock and a Show Desktop button. Your AI assistants sit in the Start panel.
  • Mouse-friendly. You never have to type a command to get things done.
  • Wallpapers. Six original 4K wallpapers to choose from.

Ready for coding

Everything you need to start building is already installed.

  • Code editor. Visual Studio Code, with helpful extensions.
  • Languages. Node.js, Python and Go.
  • Tools. Git, Docker and a modern terminal.

Everyday apps

A computer is more than a code editor.

  • Web and writing. Chromium browser, Obsidian notes and LibreOffice.
  • Create. Video editing, screen recording and image editing.
  • Handy extras. Clipboard history, a task manager and easy file sharing.

Easy upkeep

One tool keeps everything healthy.

  • Update everything. Run noc update, or click through the control panel.
  • Check your system. Run noc doctor to see that everything is working.
  • New accounts. New user accounts start with the same default settings and app configuration.
