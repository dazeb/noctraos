Features

What is in the box

Noctra sets everything up for you the first time you log in. There is nothing to assemble.

AI on your own computer

The AI models run on your PC, not on someone else's server.

  • Picks models that fit. Coming soon Noctra will check your processor, graphics card and memory, then show which models run well.
  • Private prompts. With a local model, your prompts and files stay on your computer. Online assistants send what you give them to their own servers.
  • Simple model list. Pick a model from a list and download it from a window.
  • Right-click to explain. Right-click any file and ask the AI what it says.

AI coding assistants

Six assistants sit in the start menu. Each one opens in a terminal and sets itself up the first time you use it.

Codex
Claude Code
OpenCode
Grok
Gemini CLI
Qwen Code
  • One menu. Codex, Claude Code, OpenCode, Grok, Gemini CLI and Qwen Code.
  • In your editor. The code editor comes ready to chat with your local model.
  • Optional session manager. Herdr, included with Noctra, keeps terminal sessions running after you close the window.
  • Your own accounts. Online assistants need their own account and an internet connection.

A calm dark desktop

Easy on the eyes, and it works the way you expect.

  • Dark theme. Charcoal with amber highlights.
  • Familiar layout. A start menu and taskbar, with AI at the top of the menu.
  • Mouse-friendly. You never have to type a command to get things done.
  • Wallpapers. Five original 4K wallpapers to choose from.

Ready for coding

Everything you need to start building is already installed.

  • Code editor. Visual Studio Code, with helpful extensions.
  • Languages. Node.js, Python and Go.
  • Tools. Git, Docker and a modern terminal.

Everyday apps

A computer is more than a code editor.

  • Web and writing. Chromium browser, Obsidian notes and LibreOffice.
  • Create. Video editing, screen recording and image editing.
  • Handy extras. Clipboard history, a task manager and easy file sharing.

Easy upkeep

One tool keeps everything healthy.

  • Update everything. Run zom update, or click through the control panel.
  • Check your system. Run zom doctor to see that everything is working.
  • New accounts. New user accounts start with the same default settings and app configuration.
