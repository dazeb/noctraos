How it works

Three steps. No setup in between.

01

Install

Add Noctra to Zorin OS 18 with one command, or boot the installer.

02

Detect

llmfit scans your CPU, GPU and memory, then lists the models that fit your PC.

03

Run

Pick a model and it runs locally. Open an agent from the start menu and start building.

Agents

Every coding agent, one click away.

Each one opens in a terminal and installs itself the first time you use it. Noctra ships launchers, not the agents. Agent names and logos belong to their projects.

Why Noctra

Like Omarchy, minus the learning curve.

  • Familiar layout top bar, Start, dock
  • Mouse-first no tiling to learn
  • Nothing to configure models picked for you

Install

One command on Zorin OS 18.

curl -fsSL https://raw.githubusercontent.com/dazeb/zorin-ai/main/boot.sh | bash

Starting from a blank disk? Build the installer ISO from the repository. There is no hosted download yet.
