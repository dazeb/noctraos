What is Noctra OS?

A Linux desktop with AI already set up.

Noctra OS is based on Ubuntu, a familiar starting point if you are new to Linux. The first time you log in, Noctra sets up the AI models, assistants and coding tools for you.

Graphics card ready for AI

Noctra installs NVIDIA and AMD graphics drivers, plus CUDA or ROCm, so local AI models use your graphics card.

AI assistants in the start menu

Hermes and six AI coding assistants, such as Claude Code and Codex, are one click away.

Ready for coding

A code editor, programming languages and developer tools are already installed.

Get started

Ready to try it?

Download the installer, write it to a USB stick and boot. Noctra sets itself up on first login.
