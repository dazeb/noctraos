A graphics card is optional. Models run on the CPU, and use an NVIDIA GPU when one is detected.

Installing

Four steps.

  1. Write it to a USB stick.Use any tool that writes ISO images, such as balenaEtcher or Ventoy.
  2. Boot from the stick.Pick “Try or Install Noctra OS” and click through the installer. Or choose the unattended entry if the ISO was built with it.
  3. Log in.A terminal opens on first login and asks once for your password. It then builds the workstation.
  4. Check it.Run zom doctor to confirm that everything is healthy.
