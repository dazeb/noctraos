The virtual machine disks are trial appliances. They sign in automatically as the user noctraos with the password noctraos, and that user has passwordless administrator (sudo) access. Change the password first by opening a terminal and running passwd. Use the disk to try Noctra OS, not for real work, and keep it off shared networks.

This is an alpha release, and it moves fast. Updates are constant and things will break. Noctra OS 0.5.0 has been run in virtual machines and has seen little testing on real hardware, so a virtual machine is the safest way to try it: if it breaks, delete it and start again. Back up anything important before you write the installer to a real disk, and tell us how it went.

Using a virtual machine? Create a new machine, attach the disk file as its hard drive, and start it. Prefer to build it yourself? The README has the instructions.

Preview means less tested. The KDE Plasma edition has run in virtual machines only. Broad theme acceptance and real-hardware acceptance remain untested. Known issue in these 0.5.0 Plasma files: after an interactive install the first-boot setup does not start by itself; open Konsole and run /usr/local/sbin/noctraos-firstboot. It is fixed for the next release. The GNOME edition above remains the recommended download. Please tell us what you find.

Super+Space search for this edition (files, clipboard history, opt-in browser history and web search through KRunner) is built and being prepared as an optional update for existing installs; it is not in the 0.5.0 files above.

Check your download

The files are large. A quick check confirms that nothing was lost on the way. Download SHA256SUMS into the same folder, then run:

Linux

sha256sum -c SHA256SUMS --ignore-missing

Windows (PowerShell). This prints a checksum for each Noctra file in the folder. Compare each one with the SHA-256 shown beside that file above, or with its line in SHA256SUMS.

Get-FileHash .\noctraos-0.5.0* -Algorithm SHA256

Linux prints OK next to each file that matches. If a file does not match, download it again.

System requirements

Intel or AMDprocessor
25 GBfree disk space
8 GB memory16 GB for larger models
Internetduring install

First setup takes 25 to 40 minutes, mostly installing the workstation apps and building Hermes Desktop. Local AI is a separate, optional step. It installs Ollama, LLMFIT and, after you agree, the tools for a supported NVIDIA or AMD graphics card. It downloads no model until you choose one. Without a separate graphics card, local models run on the processor.

Installing

Four steps.

  1. Put it on a USB stick.The installer is a single .iso file. A free tool such as balenaEtcher or Ventoy copies it to the stick.
  2. Start your PC from the stick.Choose the “Try or Install” entry in the boot menu and click through the installer.
  3. Log in.A short welcome opens while a window asks once for your password and installs the workstation apps and tools. Setup takes 25 to 40 minutes and needs an internet connection. Local AI and personal accounts remain your choice.
  4. Check it.Run noc doctor to confirm that everything is working.
