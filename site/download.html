The virtual machine disks are trial appliances. They sign in automatically as the user noctraos with the password noctraos, and that user has passwordless administrator (sudo) access. Change the password first by opening a terminal and running passwd. Use the disk to try Noctra OS, not for real work, and keep it off shared networks.

This is an early release. Noctra OS 0.3.0 has been run in virtual machines, and has seen little testing on real hardware. Back up anything important before you write the installer to a disk, and tell us how it went on your PC.

Using a virtual machine? Create a new machine, attach the disk file as its hard drive, and start it. Prefer to build it yourself? The README has the instructions.

Check your download

The files are large. A quick check confirms that nothing was lost on the way. Download SHA256SUMS into the same folder, then run:

Linux

sha256sum -c SHA256SUMS --ignore-missing

Windows (PowerShell). This prints a checksum for each Noctra file in the folder. Compare each one with the SHA-256 shown beside that file above, or with its line in SHA256SUMS.

Get-FileHash .\noctraos-0.3.0* -Algorithm SHA256

Linux prints OK next to each file that matches. If a file does not match, download it again.

System requirements

Intel or AMDprocessor
25 GBfree disk space
8 GB memory16 GB for larger models
Internetduring install

First setup takes 25 to 40 minutes, mostly downloading the AI model and building the Hermes app, which adds about 5 GB. A separate graphics card is optional. If you have an NVIDIA or AMD card, setup installs its driver (with CUDA for NVIDIA, ROCm for supported AMD cards) and local models use it after one restart. Without one, models run on the processor.

Installing

Four steps.

  1. Put it on a USB stick.The installer is a single .iso file. A free tool such as balenaEtcher or Ventoy copies it to the stick.
  2. Start your PC from the stick.Choose the “Try or Install” entry in the boot menu and click through the installer.
  3. Log in.A short welcome opens while a window asks once for your password and sets everything up. Setup takes 25 to 40 minutes and needs an internet connection.
  4. Check it.Run noc doctor to confirm that everything is working.
