Check your download

The files are large. A quick check confirms that nothing was lost on the way. Download SHA256SUMS into the same folder, then run:

Linux

sha256sum -c SHA256SUMS --ignore-missing

Windows (PowerShell). Compare the result with the line for your file in SHA256SUMS.

Get-FileHash .\noctraos-0.3.0-amd64.iso -Algorithm SHA256

Linux prints OK next to each file that matches. If a file does not match, download it again.

System requirements

Intel or AMDprocessor
25 GBfree disk space

A separate graphics card is optional. If you have an NVIDIA or AMD card, setup installs its driver (with CUDA for NVIDIA, ROCm for supported AMD cards) and local models use it after one restart. Without one, models run on the processor.

Installing

Four steps.

  1. Put it on a USB stick.The installer is a single .iso file. A free tool such as balenaEtcher or Ventoy copies it to the stick.
  2. Start your PC from the stick.Choose the “Try or Install” entry in the boot menu and click through the installer.
  3. Log in.A short welcome opens while a window asks once for your password and sets everything up. Setup takes about half an hour and needs an internet connection.
  4. Check it.Run noc doctor to confirm that everything is working.
