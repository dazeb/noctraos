Download

Get Noctra OS 0.3.0

Two ways in: add Noctra to a Zorin OS 18 install, or build the installer ISO.

Already on Zorin OS 18

Run the installer

Clones the repository and runs the setup. It takes a while: models and apps are downloaded.

curl -fsSL https://raw.githubusercontent.com/dazeb/zorin-ai/main/boot.sh | bash

Prefer to read it first? git clone https://github.com/dazeb/noctraos, then run ./boot.sh.

Fresh disk

Build the installer ISO

A remastered Zorin OS 18.1 image with Noctra baked in. There is no hosted download yet, so you build it from the repository.

sudo ./iso/build-zorin-ai-iso.sh Zorin-OS-18.1-Core-64-bit.iso noctra.iso

The build needs about 25 GB of scratch space. Build instructions

A graphics card is optional. Models run on the CPU, and use an NVIDIA GPU when one is detected.

Installing from the ISO

Four steps.

  1. Write it to a USB stick.Use any tool that writes ISO images, such as balenaEtcher or Ventoy.
  2. Boot from the stick.Pick “Try or Install Noctra OS” and click through the installer. Or choose the unattended entry if the ISO was built with it.
  3. Log in.A terminal opens on first login and asks once for your password. It then builds the workstation.
  4. Check it.Run zom doctor to confirm that everything is healthy.
