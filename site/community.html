Get involved

Help build Noctra

Noctra OS is an alpha project, changing daily, and we need contributors. You do not need to be a Linux expert: bug reports, testing, docs, design and code all help.

Where we need help

Pick something small.

Because Noctra moves fast and is still alpha, the most valuable thing you can do is run it, break it and tell us how. No big proposal needed.

  • Test itBoot a VM disk or a spare PC, and report what worked, what confused you and what your hardware is. Real-hardware reports are rare and precious.
  • Fix and buildPick a bug, improve search, or help with themes, apps and setup. Runtime changes are tried in a throwaway VM, never on your own machine.
  • Explain itFix a typo, improve a guide, or make the first-run instructions clearer. Docs and screenshot changes need no OS rebuild.
  • Make it look betterShare screenshots, accessibility feedback or design ideas for the desktop and this website.

Contributing

Noctra OS is a set of setup scripts plus a few small tools. Not sure where to start? Open an issue, say what interests you and how much experience you have, and we will work out a useful first step together.

For a larger change, open an issue first so we can agree on the approach before you write code. The contributing guide covers forks, branches, checks and where things live.

There is no license yet, so please check with the maintainer before sending a large change.

Noctra is not an official Ubuntu flavour. If you are looking for Ubuntu support, see ubuntu.com/community.

Contact

The way to reach us is email: admin@noctraos.dev. There is no contact form. That is the address for questions, press, partnerships and anything you would rather not post in public.

To report a security problem, write to the same address with Security in the subject. Please give us a chance to fix it before you share the details, and we will tell you when it is fixed.

For bugs and ideas, GitHub issues are the best place, because other people can see and add to them.

We will list our social accounts here once we have them.
