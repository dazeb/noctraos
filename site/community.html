Contributing

Noctra OS is a set of setup scripts plus a few small tools. If you want to change something, open an issue first so we can agree on the approach before you write code.

There is no license yet, so please check with the maintainer before sending a large change.

Noctra is not an official Ubuntu flavour. If you are looking for Ubuntu support, see ubuntu.com/community.
