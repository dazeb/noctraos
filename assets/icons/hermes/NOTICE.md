# Hermes icon

`hicolor/*/apps/hermes.png` is the Hermes Desktop app icon, taken unchanged (only scaled to
48, 128, 256 and 512 px) from `apps/desktop/assets/icon.png` in
https://github.com/NousResearch/hermes-agent. NoctraOS does not redraw it.

Hermes Agent is released under the MIT License, Copyright (c) 2025 Nous Research. The licence
text is in that repository's `LICENSE` file.

Installed system-wide by `install/06_desktop_theme.sh` so the Hermes launcher
(`configs/applications/noctraos-hermes.desktop`, `Icon=hermes`) has its icon for every account,
before and independent of the Hermes build in module 11.
