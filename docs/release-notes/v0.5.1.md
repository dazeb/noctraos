## What's new in 0.5.1

- **The Plasma edition now sets itself up after an interactive install.** In 0.5.0 the first-boot setup of the KDE Plasma
  edition never started when you installed it with the graphical installer (Plasma 6 ignores a terminal flag that GNOME
  honours). It now opens in Konsole by itself, asks for your password, and provisions the system. Checked on a fresh
  interactive install of this release's ISO. The 0.5.0 Plasma ISOs have the bug: on one of those, run
  `/usr/local/sbin/noctraos-firstboot` in Konsole once.
- **Super+Space search on Plasma.** Meta+Space (KDE's name for Super+Space) opens KRunner. KDE's own results supply
  applications; Noctra adds files, clipboard history, opt-in browser history and web search. The AI-first Start menu
  categories are still not done.
- **`noc doctor` checks Node.js for the Node2Shell bug (CVE-2026-111497).** It warns when the Node.js from mise, or the
  one Hermes brings, is older than 22.23.4, 24.22.1 or 26.12.1, and says how to update. `noc update` updates the
  mise one. Both editions.
- **The KDE edition is called Plasma** in the installer, the download page and the docs. Kubuntu 26.04 is the base it
  is built on.
- **Downloads now come from Hetzner.** The ISOs, VM disks, checksums and torrents of this release are served from
  Hetzner Object Storage. Files of 0.4.0 and 0.5.0 were copied across; older versions are not kept there.

## Known issues

- **The Plasma edition is still a preview.** The Start menu categories are not ported, some settings still look like
  stock Kubuntu, and the first session after setup shows the stock panel until the next login. It has run in virtual
  machines only. The full list is in `docs/flavours.md`.
- Real hardware and the NVIDIA and ROCm driver paths have not been tested. The ISOs and the VM disks have been run in
  virtual machines.
- The VM disks sign in automatically as `noctraos` (password `noctraos`) with passwordless sudo. They are for trying
  Noctra OS, not for real work.
