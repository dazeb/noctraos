## What's new in 0.5.0

- **A KDE Plasma edition, as a preview.** The same Noctra OS on Kubuntu 26.04 LTS with the KDE Plasma 6 desktop (the
  `kubuntu` flavour): its own installer ISO, QCOW2 and VMDK disks, in their own folder next to the GNOME files. The
  installer, login screen, boot splash, lock screen and desktop theme are Noctra's. It is a preview: see the known
  issues below before you rely on it. The GNOME edition (on Zorin OS 18.1) stays the main one.
- **Local AI is your choice, not part of the first run.** The first setup no longer installs Ollama or downloads a
  model. The AI models page offers "Set up local AI…" with what it installs and how much disk it needs, and it never
  downloads a model unless you pick one. Once it is set up, Ollama starts with the computer only if you turn that on.
- **Only what Noctra itself needs.** Node is the only language installed for you (the coding agents and Hermes use
  it). Add others with `mise use -g`. Existing machines keep what they have.
- **A bigger virtual disk is noticed.** If you enlarge a VM's disk after installing, the Control Panel's Hardware page
  (and `noc disk`) offers to grow the system partition into the new space, online, after you say yes.
- **The Software Updater no longer freezes.** Every image up to 0.4.0 lost file ownership when it was built, which
  stopped the update service from starting. The images are fixed, and installed machines are repaired by an update.
- **The Privacy page** says plainly whether remote login is on, how much clipboard history is kept, and how saved
  passwords are stored, with a switch or a button for each.
- **Every setup chore can be skipped.** Git identity, the GitHub sign-in and GPU setup each have a "No, I'll set it up
  myself" button, and every action page has a quiet Terminal button that shows the `noc` command behind it.
- **Virtual machines get their guest tools first** (QEMU/Proxmox, VMware, VirtualBox, Hyper-V), so the host sees the
  machine's address from the first boot.
- **Agents know the system.** A NoctraOS skill is installed for Hermes, Claude Code and Codex, so they can answer
  questions about `noc`, the Control Panel and where things live.
- Behind the scenes: the first boot fetches the newest provisioner even without git, and updates for installed
  machines are published from the release pipeline.

## Known issues

- **The KDE Plasma edition is a preview.** Super+Space search and the Start panel are not ported yet (they are
  GNOME Shell extensions; the Plasma version will use KRunner and Kickoff). KDE's own Welcome Center still opens
  next to Noctra's welcome on the first login, and Kubuntu's "HOW-TO Guides" and "Kubuntu Website" icons are on the
  desktop. It has run in virtual machines only.
- The Proxmox install script offers the GNOME edition only. To try the KDE Plasma edition on Proxmox, import its
  QCOW2 by hand or boot its ISO.
- A full interactive install of the installer ISOs, real hardware, and the NVIDIA and ROCm driver paths have not
  been tested. The ISOs and the VM disks have been run in virtual machines.
- The VM disks sign in automatically as `noctraos` (password `noctraos`) with passwordless sudo. They are for trying
  Noctra OS, not for real work.
