## What's new in 0.3.2

- **Super+Space and the Start panel work on the first sign-in.** Until now the first login needed one sign-out and sign-in before they loaded. The installer now ships those pieces already in place.
- **Window corners are clean.** The dark wedge at the top-left of GTK windows (Welcome, Software Updater) is gone: the theme now squares every corner, not only the frame.
- **Health shows a Flatpak security check.** Flatpak 1.18.4 fixed six security bugs. The check passes on 1.18.4 or newer, or when your distribution has back-ported the fix, and warns otherwise. Ubuntu 24.04, our base, ships an older Flatpak, so expect that warning until Ubuntu patches it.
- **The AI models page says what each model can do** (chat, tool use, images, embeddings and so on), when Ollama reports it.
- **The Control Panel's About page shows the NoctraOS logo** at full size, and still shows it where the icon theme does not have it.
- **Fixed:** the Control Panel's card tooltip said "Open Ai Models"; it now says "Open AI models".
- **The website has a Contact link** (email only: admin@noctraos.dev).
- This is the first release built and published by the release pipeline, from the tagged commit.

## Known issues

- A full interactive install of the installer ISO, real hardware, and the NVIDIA and ROCm driver paths have not been tested. The ISO and the VM disks have been run in virtual machines.
- The VM disks sign in automatically as `noctraos` (password `noctraos`) with passwordless sudo. They are for trying Noctra OS, not for real work.
