NOCTRAOS

Start here.

Everything is where you would expect it, and you can do it all with the mouse. There is one shortcut worth learning.

Super + Space

Press the Windows key and Space and type. One box finds your apps, files and folders, clipboard history and the web. If you let it, it also finds pages from your browser history. Press Esc to close it.

WHERE THINGS ARE

  • Start button (the N) in the dock at the bottom opens the Start panel: your AI agents, recent files and a settings gear.
  • Dock at the bottom holds your apps. Right-click an app for its options.
  • Top bar: the button on the left shows your desktop; the clock in the middle opens your notifications and calendar; the right side has background apps, network, sound and power. Open the power menu for lock, settings and shutdown.
  • Task Manager is Mission Center. Search for it, or find it in the dock.
  • Files is in the dock. Right-click a file, then Scripts, for Ask AI to Explain, Open in VS Code and Open Terminal Here.
  • Clipboard history is kept for you. Find anything you copied from Super+Space.

YOUR AI

  • Agents (Claude Code, Codex, OpenCode, Grok, Gemini CLI, Qwen Code) are in the top row of the Start panel. The first time you open one it offers to install it.
  • Local models run on this computer through Ollama, so your files stay here. Manage them from All apps, then Local LLM.
  • VS Code comes with Continue already connected to your local model.

MAKE IT YOURS

  • The gear in the Start panel opens Settings.
  • The gear in the search box changes what Super+Space looks through, including browser history.
  • Hide the “New users start here” strip or the weather from the Start panel at any time.

IF SOMETHING LOOKS WRONG

  • Open Terminal and run zom doctor for a health check, or zom update to update everything.
  • Search for AI Health Check in Super+Space for the same check without a terminal.
