# The desktop (zorin flavour: GNOME on Zorin OS 18.1)

The kubuntu flavour (KDE Plasma) is in progress and implements the same product behaviour differently. Desktop code lives in `install/desktop/<desktop>/` (planned) or in a module whose second line is `# desktops: gnome|plasma|any`. Skipped desktop work prints `NOT APPLIED`.

## Super+Space search (headline feature)

One overlay reaches applications, files and folders, clipboard history, the web, and (opt-in) browser history. It takes over Super+Space and moves the input-source switch to Shift+Super+Space.

- `extensions/noctraos-search@noctraos.local` - the overlay; `search/` - the app (`core.py` file index in SQLite, CopyQ bridge, `browsers.py`, `preferences.py`, settings window `noctraos-search --settings`); a systemd user timer refreshes the index (units in `configs/systemd/`); `configs/gsettings/` holds the schemas.
- **Indexes the home folder, not `/`** (`roots` defaults to `['~']`; `/` floods results with system paths). A user's saved `roots` is kept.
- **Browser history is opt-in**, offered after first use via a "Finish setup" notice in the overlay (**Set up** / **Not now**, reversible in Search settings). History is copied to `~/.cache/noctraos-search/history` (mode 0700) and searched locally; nothing is uploaded.
- Installed by `install/09_super_search.sh`; also baked into the ISO.

## Start panel, dock, top bar

- `extensions/noctraos-start@noctraos.local` replaces the Start button's popup by hooking a **private Zorin Menu API** (`menuButtons[i]._menu.toggle/open`). It takes a modal grab on a full-screen root actor and decides "outside click" by pointer coordinates (`event.get_source()` is null for clicks on the root; a stage `captured-event` handler never fires under a grab - both were tried and failed).
- `extensions/noctraos-branding@noctraos.local` - flat top bar, Show Desktop, tints CopyQ's tray icon (indicator id `CopyQ_copyq`, `MONO_TRAY_IDS`) with a `Clutter.ColorizeEffect` because the tray icon ignores the icon theme.
- Layout comes from **settings, not patches**: `branding/setup-branding.py` (once per account, marker `desktop-layout-v1`) turns on the Zorin Taskbar's `stockgs-keep-top-panel`, makes a centred dock (`panel-lengths` -1) and trims elements. To change an existing account's layout, delete the marker and re-run the script. `docs/desktop-layout.md`.
- The Start panel shows weather via `noctraos-weather` (Open-Meteo, keyless; the city is the user's choice, `noctraos-weather --setup`) and opens `help/index.html` ("New users start here").
- **GNOME Shell scans for extensions once, at start**: anything installed into a running session is invisible until the next login on Wayland. Hence extensions, schemas, search app and setup autostarts are baked into the squashfs (`iso/bake-shell.sh`); module 09 still installs them for `boot.sh` installs on an existing system (sign out/in needed). Keep the two file lists in step. Menu-tree changes also need a session rescan (logout/reboot); Wayland has no in-place shell restart.

## Theme

- Source of truth: `configs/theme/palette.json` (dark + amber), templates/remaps rendered by `scripts/render-theme.py` (`--check` verifies committed outputs match) and `scripts/build-desktop-theme.py`. Derived, not shipped: NoctraOS-Dark shell + GTK themes (module 08), a small icon theme `assets/icons/noctraos-theme` inheriting ZorinGrey-Dark, white SVG overrides under stock icon names in `assets/icons/overrides`, Herdr and btop palettes, terminal/app palette. Design notes: `docs/theme-design.md`.
- **Clamp every radius spelling**, not just `border-radius` (Zorin uses `border-top-left-radius` and `-gtk-outline-*-radius`); `RADIUS_DECLARATION` covers them and tests pin it.
- Zorin's theme defaults live in `:zorin` session groups of gschema overrides and a session group beats a plain group: an override setting only the plain group is silently ignored for theme keys. Repeat the `:zorin` group names (as `90_noctraos-live.gschema.override` does).
- Module 06 owns gsettings ergonomics. It defines a local `gs()` helper; **other modules must not call bare `gs`** (it is the Ghostscript binary). Use `as_user gsettings set ...`. Desktop settings are warn-not-die.
- We fix the theme and layout, so there is no theme switcher: `noctraos-appearance` only does wallpapers and fonts.

## Wallpapers

Six seeded 4K JPEG scenes in `/usr/local/share/backgrounds/noctraos` (generated by `assets/wallpapers/generate-wallpapers.py`). `noc bg list|set <file>|next` (sets `picture-uri` and `picture-uri-dark`); Settings > Background also works.

## Clipboard (CopyQ)

History preseeded (`configs/copyq/copyq.conf`, 1000 entries, silent, tray); Super+Space searches it. **CopyQ must run with `QT_QPA_PLATFORM=xcb`** (as native Wayland it cannot record on GNOME); `bin/noctraos-copyq` is the autostart wrapper and also sets the session `iconColor` white. See [privacy-and-accounts](privacy-and-accounts.md) for clearing it.

## Files app and menus

- Nautilus right-click scripts (`configs/nautilus-scripts/`): "Open in VS Code", "Ask AI to Explain", "Open Terminal Here". Names use plain spaces (a menu label eats `_` as a mnemonic marker). They get selections from env vars (`NAUTILUS_SCRIPT_SELECTED_FILE_PATHS`), not argv.
- AI-first app menu: `configs/xdg/gnome-applications.menu` installed to `/etc/xdg/menus/`. Launchers and `.directory` files are in `configs/applications/`.
- `zorin-menu.desktop` does not exist on Zorin 18; favorites/menu code skips missing entries by design. `org.gnome.desktop.interface accent-color` is absent on 18.1 (the attempt warns and moves on).

## Welcome app and appearance

`noctraos-welcome` (GTK; replaces Zorin's tour; `--force`, `--provisioning`) and `noctraos-appearance`. **Python GUI apps must pin `#!/usr/bin/python3`**: a mise-managed `python3` first on PATH has no PyGObject. The Welcome app repeats the Git/GitHub terminal commands as text (a test pins them to `TERMINAL`).

## Boot chain

Plymouth splash (`assets/boot/plymouth/noctraos`, **two-step** only, loops `throbber-*.png`; `UseProgressBar=true` replaces the throbber) and GRUB theme (`assets/boot/grub/noctraos`; gfxmenu ignores `progress_bar` height, so a text countdown is used), isolinux splash for the ISO. Module 10 applies them for non-ISO installs. Regenerate with `assets/boot/generate-boot-assets.py` (outputs committed; JetBrains Mono, OFL). Unattended-install GDM note: the GDM greeter is broken on Zorin 18.1, so unattended builds default to autologin.
